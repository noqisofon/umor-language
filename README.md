# umor-language

Umorは、日本語プログラミング言語Mind（FORTH系、分かち書き構文）から着想を得た、
Rust製の新しい言語処理系です。Mindの構文思想（分かち書き・送り仮名の無視・単語定義）を
踏襲しつつ、型システムはFactor（型付きスタック言語）寄りに設計しています。

## 現在の実装状況

- 字句解析器（Tokenizer） — 実装済み
- パーサ（構文解析器、フェーズ1） — 実装済み
  - ワード定義（`とは`/`は` 〜 `。`）、局所処理単語（`本体とは`）、
    条件分岐（`ならば`/`そうでなければ`/`つぎに`）、変数宣言（`Xは 変数`）、
    `（）`添字アクセス糖衣構文の脱糖衣に対応
  - 変数の兄弟スコープチェックは別パス（`umor::parser::check_scopes`）
- 単語辞書（Dictionary） — 未実装
- コンパイラ／スタックマシン（VM） — 未実装
- 型検査器 — 未実装
